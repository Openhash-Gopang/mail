나비웹 도우미 — 개인정보 처리방침

운영: 주식회사 나비웹(Naviweb Inc.), 제주 · 시행일 2026-11-06

1. 이 프로그램이 하는 일

나비웹 도우미는 Chrome 확장 프로그램입니다. 사용자가 나비웹(naviweb.kr)에서 맡긴 웹 사이트 작업(예: 인터넷등기소에서 법인등기사항증명서를 전자소송용으로 발급 신청하는 서류 절차)을 사용자의 브라우저 화면에서 단계별로 대신 진행합니다. 어느 사이트든 맡길 수 있지만, 사이트마다 사용자의 허용이 필요합니다.

2. 사용자 승인

  • 작업은 사용자가 사이드 패널의 시작을 눌러야 시작됩니다. 나비웹 화면 자체는 조작하지 않습니다.
  • 처음 가는 사이트마다 사용자가 이 사이트 허용을 누르고 Chrome의 허용 창에서 승인해야 합니다. 승인하지 않은 사이트는 읽거나 조작하지 않습니다.
  • 기본 사이트(인터넷등기소, 전자소송, 정부24, 나비웹) 밖에서는 이동·입력·클릭마다 사용자 확인을 받습니다.
  • 제출·발급·전송·삭제 버튼은 항상 사용자 확인을 받습니다. 로그인·공동인증서·간편인증·결제·보안문자는 사용자가 직접 하며, 비밀번호·카드번호·주민등록번호는 입력하지 않습니다.

3. 처리하는 정보

  • 화면 내용: 작업 중인 탭에서 보이는 버튼·입력칸의 이름과 값, 본문 글자(필요하면 화면 이미지)를 읽어 AI 모델에 보내 다음 동작을 정합니다. 비밀번호 입력칸의 값은 읽지 않습니다.
  • 나비웹 로그인 토큰: 사용자가 나비웹에서 작업을 맡길 때 받아, 요청한 사용자인지 확인하는 데만 씁니다. 브라우저를 닫으면 지워집니다(세션 저장소).
  • 맡긴 작업 내용: 절차 이름과 지시문(예: 법인 이름)을 기기 안에 임시 저장하고, 사용자가 지우거나 시작하면 없앱니다.
  • 받아 온 서류 파일: 사용자가 맡긴 첨부서류가 파일로 발급되면 내려받아 나비웹 화면으로 전달합니다. 파일 내용과 내려받기 주소는 AI 모델로 보내지 않으며, 확장 프로그램은 파일을 보관하지 않고 나비웹 화면으로 한 번 전달만 합니다. 서류에 넣을지는 나비웹 화면이 사용자에게 확인합니다.

4. 보내는 곳

화면 내용과 지시문은 나비웹 게이트웨이(Cloudflare)를 거쳐 AI 모델 제공자(Anthropic)에게 전달되어 답을 받는 데만 쓰입니다. 나비웹은 이 내용을 저장하지 않으며, 광고·판매 목적으로 쓰거나 제3자에게 제공하지 않습니다. 모델 제공자의 처리는 해당 제공자의 정책을 따릅니다.

5. 보관과 삭제

확장 프로그램의 설치와 업데이트는 Chrome 웹 스토어를 통해 이루어지므로 구글이 배포 정보(설치 수, 업데이트 요청 등)에 관여합니다. 확장이 읽은 화면 내용은 구글로 보내지 않습니다.

기기 안의 임시 정보는 위 3항대로 지워집니다. 확장 프로그램을 삭제하면 모든 데이터가 함께 삭제됩니다. 게이트웨이는 요청 내용을 보관하지 않고, 남용 방지를 위한 사용 횟수만 일시적으로 셉니다.

6. 요청하는 권한

  • activeTab, scripting, tabs, webNavigation: 작업 중인 탭과 그 안의 화면 구성을 읽고 조작하기 위해
  • storage, sidePanel: 맡긴 작업과 설정 저장, 작업 진행·승인 창 표시
  • downloads: 서류를 내려받은 기록에서 방금 받은 파일의 주소를 확인해 나비웹으로 전달하기 위해
  • 선택적 사이트 접근(https://*/*): 사용자가 사이트별로 승인한 경우에만 사용
